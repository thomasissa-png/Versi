## Pourquoi le GEO est N/A

1. **Outil interne, pas de vitrine publique** — Versi Studio est une interface fonctionnelle (upload de plans, découpe de lots, génération de visuels IA). Il n'y a pas de contenu éditorial, de blog, ni de pages publiques que les LLMs peuvent crawler et citer.

2. **robots.txt : noindex, nofollow** — L'intégralité de l'outil est bloquée à l'indexation. Aucun contenu ne doit être référencé par les moteurs de recherche ni ingéré par les LLMs.

3. **Pas de llms.txt** — Le fichier llms.txt guide les LLMs sur l'interprétation du contenu. Sans contenu public, il est inutile.

4. **Pas de Schema.org SaaS** — Le balisage structured data (SoftwareApplication, SaaS) est réservé aux pages publiques visant un référencement organique. Non pertinent ici.
