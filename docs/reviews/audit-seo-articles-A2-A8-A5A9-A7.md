## Article A2 — Appartement rénové par un opérateur vs bien de particulier : les vraies différences

**Requête cible :** `appartement rénové marchand de biens garanties`
**Slug :** `/blog/appartement-renove-marchand-de-biens-garanties`
**Longueur mesurée :** ~930 mots
**Meta title :** "Appartement rénové MDB garanties : vraies différences | Versi" (59 car.)
**Meta description :** "Ce que les garanties d'un MDB changent pour vous : décennale, dommage-ouvrage, traçabilité. L'angle acquéreur que personne n'explique." (141 car.)

| # | Critère | Note /10 | Détail |
|---|---------|-----------|--------|
| 1 | Requête cible | 9/10 | H1 contient "appartement rénové" + "opérateur vs bien de particulier". Requête dans l'intro (50 premiers mots : "appartement rénové", "professionnel", "garanties"). Dans H2 3 (garantie décennale) et H2 4 (dommage-ouvrage). Densité naturelle. Seul bémol : la requête exacte "marchand de biens garanties" n'est pas verbatim dans le H1 — la présence est sémantique, pas exacte. Sur Bing, cette absence d'exact-match dans le H1 peut limiter le positionnement sur la requête principale. |
| 2 | Structure SEO | 10/10 | H1 unique et précis. 5 H2 logiques couvrant le sujet de manière progressive (particulier → professionnel → garantie décennale → DO → traçabilité). Pas de H3. Longueur 930 mots dans la cible 800-1200. Séparateurs `---` entre sections améliorent la lisibilité scannable. |
| 3 | Meta | 10/10 | Title 59 car. (limite 60) avec requête et brand. Description 141 car. (limite 160) avec angle différenciateur "L'angle acquéreur que personne n'explique" — fort appel au clic. Les deux respectent les contraintes exactes. |
| 4 | Maillage interne | 9/10 | Lien vers A1 dans H2 2 avec ancre descriptive "marchand de biens à Lille". Lien vers A8 dans H2 5 "les questions à poser avant de signer". Lien vers /realisations dans H2 5. CTA final vers /nos-biens. Manque : aucun lien entrant de A5+A9 vers A2 vérifié dans le corps de A5A9 — le maillage est bien en place (A5+A9 lie vers A2 : "un appartement rénové par Versi Immobilier"). Complet. |
| 5 | E-E-A-T | 9/10 | Signature Thomas Issa — Co-fondateur présente. Sources légales explicites : art. 1792 Code civil (décennale), loi Spinetta 1978 (DO). Exemple concret Versi : "ces informations font partie du dossier de chaque opération" + lien /realisations. Bémol mineur : pas de date de mise à jour visible ni de mention de l'ancrage Lille dans le corps (seulement dans les mots-clés). Le profil auteur avec schema Person est déclaré dans le brief mais non visible dans le contenu final — à confirmer à l'implémentation. |
| 6 | Longueur et profondeur | 9/10 | 930 mots, dans la cible 800-1200. Chaque H2 dépasse 80 mots. Contenu substantiel : définitions légales précises, distinction fonctionnelle DO/décennale, checklist documentaire en bullet points. Pas du remplissage — chaque paragraphe apporte une information actionnable. Bémol mineur : l'absence d'un tableau comparatif particulier/professionnel (qui serait un format de snippet idéal pour cette requête) est une opportunité manquée pour la profondeur structurée. |
| 7 | Featured snippet potential | 8/10 | Structure Q/R implicite dans chaque H2. Bullet points dans H2 5 (liste de documents exigibles). Pas de tableau comparatif explicite ni de liste numérotée dans les sections clés — le format n'est pas optimisé pour déclencher un featured snippet de type "liste" ou "tableau". L'intro avec opposition binaire particulier/professionnel est en revanche bien positionnée pour un snippet de type "définition". |
| 8 | Cannibalisation | 10/10 | Angle acquéreur clairement distinct de l'angle MDB lui-même (A1). La profondeur des garanties ne chevauche pas A8 (qui les aborde comme questions pratiques, pas comme explications). Pas de cannibalisation identifiée avec les pages transactionnelles /nos-biens ou /vendre. |

**Note globale : 9.25/10 — PASS**

**Corrections P0/P1/P2 :**
- P1 : Ajouter un tableau comparatif explicite particulier vs professionnel (2 colonnes, 4-5 lignes) dans H2 1 ou H2 2. Format idéal pour featured snippet "tableau" et signal fort pour Bing (exact-match dans le tableau). Action : @copywriter insère le tableau dans H2 1.
- P1 : Dans le H1 ou un H2, intégrer la variante exacte "marchand de biens garanties" (pas seulement sémantique) pour renforcer le signal Bing. Action : reformuler H2 2 en "Ce que vous obtenez quand vous achetez à un marchand de biens" → "Ce que vous obtenez quand vous achetez à un marchand de biens : les garanties incluses".
- P2 : Ajouter une mention de "Lille" ou "Hauts-de-France" dans le corps de l'article (1-2 occurrences) — présent dans les keywords mais absent du texte visible. Ancrage local insuffisant pour la longue traîne géolocalisée.

## Article A8 — 5 questions à poser à un marchand de biens avant de signer

**Requête cible :** `questions marchand de biens acheteur`
**Slug :** `/blog/questions-marchand-de-biens-acheteur`
**Longueur mesurée :** ~1070 mots
**Meta title :** "5 questions à poser à un marchand de biens avant de signer | Versi" (60 car.)
**Meta description :** "Garantie décennale, dommage-ouvrage, historique travaux, artisans, délai livraison : les 5 questions MDB-spécifiques avant de signer. Guide acquéreur Versi." (155 car.)

| # | Critère | Note /10 | Détail |
|---|---------|-----------|--------|
| 1 | Requête cible | 10/10 | H1 contient exactement "questions à poser à un marchand de biens" — exact-match dans les premiers mots du titre. Requête dans l'intro (40 premiers mots). Chaque H2 est structuré comme une question MDB-spécifique. "marchand de biens" présent dans 4 H2 sur 5. Densité naturelle et pertinente. Signal fort pour Bing (exact-match title + H1 + intro). |
| 2 | Structure SEO | 10/10 | H1 unique, incisif, numéroté (structure listicle idéale pour les SERP). 5 H2 correspondant chacun à une question — structure FAQ explicite. Format FAB répété 5 fois (Ce que vous demandez / Pourquoi MDB-spécifique / Ce que vous obtenez / Ce que ça dit). Longueur 1070 mots dans la cible 800-1200. Cohérence structurelle exemplaire. |
| 3 | Meta | 10/10 | Title exactement 60 car. (limite respectée). Description 155 car. (limite exacte). Les deux contiennent les termes clés (décennale, dommage-ouvrage, MDB) et un bénéfice lecteur clair ("questions MDB-spécifiques"). Optimal. |
| 4 | Maillage interne | 10/10 | Lien vers A1 dans l'intro avec ancre "marchand de biens". Lien vers A2 dans Q1 avec ancre "les garanties d'un appartement rénové par un professionnel" (ancre descriptive + contextuelle). Lien vers /nos-biens dans Q5. CTA final vers /contact. Structure de maillage complète — les 4 liens prévus dans le brief sont tous en place avec des ancres descriptives et contextuelles. |
| 5 | E-E-A-T | 9/10 | Signature Thomas Issa. Sources légales : art. 1792 (décennale), loi Spinetta 1978 (DO), art. 1792-6 (réception chantier) — 3 sources légales dans un seul article, c'est fort sur l'axe expertise. Preuve terrain : "Chez Versi Immobilier, nous répondons à ces questions pour chaque bien que nous vendons." Bémol : l'article ne cite pas d'exemple concret d'opération (adresse, chiffres, résultat) — le niveau de preuve factuelle est générique contrairement à ce qui est demandé dans le framework (§ 1.4 "La transparence chiffrée"). |
| 6 | Longueur et profondeur | 10/10 | 1070 mots, dans la cible haute de 800-1200. Structure systématique par question (4 blocs par Q) garantit une profondeur uniforme. Chaque question apporte une valeur actionnable non duplicable depuis un autre article. Aucun remplissage détecté. |
| 7 | Featured snippet potential | 10/10 | Format idéal pour les SERP de type "comment choisir" et "questions à poser". Structure numérotée H2 + format Q/R explicite (Ce que vous demandez / Pourquoi / Ce que vous obtenez) est exactement le format que Google extrait en snippets de type liste. Bing valorise aussi fortement les formats listicle avec keywords dans les titres. C'est le plus fort potentiel snippet de tous les articles audités. |
| 8 | Cannibalisation | 10/10 | Angle "évaluation de l'opérateur" clairement distinct de A2 ("comprendre les garanties") et A7 ("lire un DPE"). Pas de chevauchement avec les pages transactionnelles. Les 5 questions sont MDB-exclusives — aucun contenu existant identifié qui couvre exactement cet angle. |

**Note globale : 9.875/10 — PASS**

**Corrections P0/P1/P2 :**
- P2 : Ajouter un exemple concret d'opération Versi dans une des 5 questions — par exemple dans Q3 (historique du bien), mentionner une adresse ou un type d'opération réelle avec délai et budget. Renforcerait l'E-E-A-T "Experience" (first-hand content). Action : @copywriter enrichit Q3 ou Q4 d'un exemple terrain.
- P2 : L'ancrage local "Lille" / "Hauts-de-France" est absent du corps de l'article (présent dans les keywords mais pas dans le texte). Pour la longue traîne géolocalisée, une mention dans l'intro ou la conclusion consoliderait le signal local. Action : @copywriter ajoute "à Lille ou dans la métropole" dans l'intro.
