## 1. Nav — Éléments de navigation

### Copy actuel

- Logo : `VERSI / IMMOBILIER`
- Items nav : `NOS BIENS` / `RÉALISATIONS` / `NOTRE APPROCHE` / `CONTACT`
- CTA secondaire : `Proposer un bien`
- CTA principal : `NOS BIENS`
- Mobile overlay CTA : `VOIR LES BIENS`

### Note copy : 6/10

### Diagnostic

La nav est propre et fonctionnelle. Mais deux problèmes.

Premier problème : la CTA secondaire "Proposer un bien" est molle. Elle dit ce que fait l'acquéreur, pas ce que fait Versi. Le registre tombe dans le service générique. La CTA principale "NOS BIENS" redouble le nav item — c'est redondant sans valeur ajoutée.

Deuxième problème : "NOTRE APPROCHE" est du jargon agence. Toutes les agences ont une page "Notre approche". Versi n'est pas une agence.

Comparaison versi.fr : sur versi.fr, chaque mot de navigation est une affirmation de métier. Ici, la nav parle comme un site immobilier banal.

### Rewrite

- Items nav : `NOS BIENS` / `RÉALISATIONS` / `QUI SOMMES-NOUS` / `CONTACT`
- CTA secondaire : `Vous vendez ?`
- CTA principal : `VOIR LES BIENS`
- Mobile overlay CTA : `VOIR LES BIENS`

Pourquoi "Vous vendez ?" : cinq caractères. Accroche directe. Pose la question que le propriétaire-vendeur se pose en lisant. Plus percutant que "Proposer un bien" qui est du registre agence.

## 2. Hero — Section principale

### Copy actuel

- Surtitre : `VERSI IMMOBILIER — LILLE`
- H1 : `On connaît chaque mur. / On vous le vend, en direct.`
- Sous-titre : `Des appartements à Lille, vendus en direct par celui qui les a portés. / Vous parlez au propriétaire — pas à un intermédiaire.`
- CTA primaire : `Voir les appartements disponibles`
- CTA secondaire : `Vous avez un bien à céder →`

### Note copy : 5/10

### Diagnostic

Le H1 est le problème central de la homepage. Trois défauts majeurs.

**Défaut 1 — Le "On" trahit le brand voice.** Le brand voice est clair : vouvoiement systématique. "On connaît" est familier, presque relâché. Sur versi.fr, on dit "Nous ne déléguons pas." — assomption affirmative, sujet Versi. "On" n'existe pas dans l'univers Versi.

**Défaut 2 — "On connaît chaque mur" est trop lyrique, pas assez factuel.** Ce n'est pas du caractère — c'est une tentative de caractère. Le caractère versi.fr vient des faits ("Quarante ans de terrain", "Pas de fonds levés"), pas des métaphores. "Chaque mur" est une image. Versi ne parle pas en images.

**Défaut 3 — Redondance H1 / sous-titre.** "En direct" apparaît dans le H1 ET dans le sous-titre ("vendus en direct"). Le sous-titre répète l'idée au lieu de l'approfondir. C'est du remplissage.

Le CTA primaire "Voir les appartements disponibles" fait 5 mots — c'est correct. Mais "appartements disponibles" est redondant (si on les vend, ils sont disponibles). "Voir les appartements" suffit. Idéalement, moins de 6 mots selon le brand voice.

### Rewrite

- Surtitre : `VERSI IMMOBILIER — LILLE`
- H1 : `Vingt et un appartements transformés. / Vendus en direct. Sans agence.`
- Sous-titre : `Vous traitez avec le propriétaire — celui qui a pris chaque décision.`
- CTA primaire : `Voir les biens`
- CTA secondaire : `Vous vendez un bien →`

Pourquoi ce H1 : les chiffres remplacent les superlatifs (règle brand voice). "Vendus en direct. Sans agence." — deux phrases nominales, deux affirmations sèches. Niveau versi.fr. Le sous-titre porte un fait unique : le propriétaire décide. Aucune redondance.

## 3. AvailableProperties — Biens disponibles

### Copy actuel

- H2 : `Ce qu'on vend en ce moment.`
- CTA : `Tous nos biens`
- État vide : `Aucun bien disponible pour le moment. Revenez bientôt.`

### Note copy : 6/10

### Diagnostic

"Ce qu'on vend en ce moment" — même problème que le Hero : le "on" est interdit dans le brand voice. De plus, "en ce moment" ajoute une temporalité molle, presque hésitante. Un opérateur qui gère 3,2M€ d'opérations ne dit pas "en ce moment".

Le CTA "Tous nos biens" est correct et sobre. Il fonctionne.

L'état vide "Revenez bientôt" est du registre boutique en ligne. Versi n'est pas une boutique. Le brand voice pour ce contexte (désengagement/vide) doit être factuel avec une issue claire — pas une invitation floue.

### Rewrite

- H2 : `Les biens disponibles.`
- CTA : `Tous nos biens` (conservé — fonctionne)
- État vide : `Aucun bien en vente actuellement. Déposez votre recherche — nous vous contactons dès qu'un bien correspond.`

Pourquoi : "Les biens disponibles" est affirmatif, neutre, sans "on". L'état vide transforme un cul-de-sac en conversion : Versi ne dit pas "revenez" — Versi dit "dites-nous ce que vous cherchez".

Note : l'état vide nécessite un formulaire ou un lien vers une page contact. Signal à documenter pour @fullstack.

## 4. Arguments — Trois arguments différenciants

### Copy actuel

**Argument 1**
- Titre : `Nous portons le bien de bout en bout.`
- Description : `Chaque bien que vous voyez ici, nous l'avons acheté et piloté — rénové ou avec un projet défini. Vous parlez au propriétaire-vendeur, pas à un agent qui lit une fiche.`

**Argument 2**
- Titre : `Rien n'est caché.`
- Description : `Diagnostics complets. Historique des travaux. Garantie décennale sur les parties structurelles. Vous recevez le dossier avant la visite, pas le jour de la signature.`

**Argument 3**
- Titre : `Le prix affiché est le prix.`
- Description : `Versi vend en direct à l'acquéreur. Pas de commission d'agence sur votre achat. Vous traitez avec le propriétaire du bien — celui qui a pris toutes les décisions.`

### Note copy : 7/10

### Diagnostic

C'est la section la plus proche du niveau versi.fr. Les titres sont affırmatifs, courts, sans adjectif auto-décerné. L'argument 2 ("Rien n'est caché.") et l'argument 3 ("Le prix affiché est le prix.") ont du caractère.

Deux problèmes résiduels.

**Problème 1 — L'argument 1 est redondant avec le sous-titre Hero.** "Vous parlez au propriétaire-vendeur, pas à un agent qui lit une fiche" répète presque mot pour mot l'idée du Hero ("Vous parlez au propriétaire — pas à un intermédiaire"). Deux sections, même information. L'une d'elles est inutile. L'argument doit aller plus loin — expliquer ce que ça change concrètement pour l'acquéreur.

**Problème 2 — "de bout en bout" est du jargon générique.** C'est la formulation exacte que n'importe quelle agence utilise. Versi ne fait pas "de bout en bout" — Versi fait acquisition + transformation + vente. C'est précis. C'est différent.

### Rewrite

**Argument 1 — Rewrite**
- Titre : `Acquis, transformé, vendu par nous.`
- Description : `Chaque bien sur ce site, nous l'avons acheté. Nous avons piloté les travaux. Nous vous le vendons. Vous ne parlez à aucun intermédiaire à aucune étape.`

**Argument 2 — Conservé.** Le titre et la description fonctionnent. Pas de rewrite nécessaire.

**Argument 3 — Conservé.** Solide. La structure "Prix affiché = prix" est directe et mémorable.

## 5. Stats — Chiffres clés

### Copy actuel

- `21` — `appartements transformés`
- `100%` — `vendus sans agence`
- `3,2M€` — `d'opérations depuis 2022`

### Note copy : 8/10

### Diagnostic

C'est la section la plus forte de la homepage. Trois chiffres, trois labels courts, zéro adjectif. C'est exactement le registre versi.fr ("Quarante ans de terrain" — fait brut, sans commentaire).

Un seul ajustement possible : "d'opérations depuis 2022" est légèrement mou comme label. "depuis 2022" est la précision utile, mais "d'opérations" est vague. "de volume" serait plus précis. Mais le défaut est mineur — ne pas réécrire ce qui fonctionne.

Seul rewrite suggéré si l'on veut monter à 9/10 :

- `3,2M€` — `de volume géré depuis 2022`

"Volume géré" est plus concret que "opérations" — il dit qu'on a piloté cet argent, pas seulement qu'on a fait des opérations.

## 6. TeamTeaser — Les trois associés

### Copy actuel

- H2 : `Versi Immobilier, c'est trois associés.`
- Intro : `Trois personnes qui portent chaque bien de A à Z, qui vous font visiter et qui vous reçoivent elles-mêmes.`
- Thomas Issa : `15 ans d'expérience — 11 actifs en compte propre à Paris`
- Maxime Lemoine : `13 ans d'expérience — 5 immeubles acquis, 24 contrats structurés`
- Carl Standertskjold-Nordenstam : `14 ans d'expérience — structuration de projets complexes`
- CTA : `Découvrir notre approche complète`

### Note copy : 5/10

### Diagnostic

Le H2 est correct mais banal. "Versi Immobilier, c'est trois associés" — OK, mais n'importe quelle holding peut dire ça. Versi a "Trois fondateurs. Quarante ans de terrain." sur versi.fr. C'est plus fort, plus dense. Le H2 du TeamTeaser doit s'aligner sur ce niveau.

Le paragraphe intro est le pire copy de la homepage. "Trois personnes qui portent chaque bien de A à Z, qui vous font visiter et qui vous reçoivent elles-mêmes" — cumul de virgules, répétitions ("qui... qui... qui..."), registre brochure immobilière standard. "De A à Z" est interdit par le brand voice implicitement (même registre que "de bout en bout"). "Elles-mêmes" est maladroit — Versi est un opérateur, pas un concierge.

Les lignes de track record sont inégales. Thomas et Maxime ont des chiffres concrets : bien. Carl n'a que "structuration de projets complexes" — c'est un titre de poste générique, pas un track record. La règle brand voice est explicite : "les faits remplacent les adjectifs" et "les chiffres remplacent les superlatifs". "Projets complexes" est un adjectif auto-décerné.

Le CTA "Découvrir notre approche complète" fait 4 mots utiles + 1 mot de remplissage ("complète"). Et "approche" est du vocabulaire agence.

### Rewrite

- H2 : `Trois fondateurs. Quarante-deux ans de terrain.`
- Intro : `Thomas, Maxime et Carl portent chaque opération de l'acquisition à la vente. Ils visitent avec vous. Ils signent avec vous.`
- Carl Standertskjold-Nordenstam : `14 ans d'expérience — 8 projets structurés, 3 opérations en co-investissement` (ou demander les vrais chiffres à Carl — ne pas inventer)
- CTA : `Notre parcours complet`

Note : le track record de Carl est marqué `[HYPOTHÈSE — chiffres à valider avec le fondateur]`. Ne pas publier sans validation.

Pourquoi le nouveau H2 : c'est la formulation exacte de versi.fr transposée sur versi-immobilier.fr. Cohérence de marque maximale. 15 + 13 + 14 = 42 ans — un chiffre réel, vérifiable.

## 7. SellerBanner — Bannière vendeur

### Copy actuel

- Corps : `Vous avez un bien à vendre à Lille ? Versi Immobilier achète en direct auprès des propriétaires. Offre ferme sous 7 jours. Aucun mandat, aucune mise en vente prolongée.`
- CTA : `Nous parler de votre bien →`

### Note copy : 7/10

### Diagnostic

C'est la deuxième section la plus forte après Stats. La structure fonctionne : question d'accroche + affirmation Versi + deux garanties concrètes (délai + absence de mandat). Le "sous 7 jours" est excellent — c'est exactement le niveau brand voice de versi.fr ("répondons en 72h").

Deux défauts.

**Défaut 1 — Le titre en gras "Vous avez un bien à vendre à Lille ?" est trop long.** 9 mots. Le brand voice dit : une idée par phrase, phrases courtes. La question peut être condensée.

**Défaut 2 — "Nous parler de votre bien" est mou comme CTA.** "Parler" est du registre conversation informelle. Versi fait des offres fermes — le CTA doit le refléter. Et "notre" dans le CTA rend Versi sujet — c'est mieux, mais l'action est vague.

### Rewrite

- Corps : `Vous vendez un bien à Lille ?`
  `Versi achète en direct. Offre ferme sous 7 jours. Aucun mandat, aucune agence.`
- CTA : `Demander une offre →`

Pourquoi : le corps passe de 32 mots à 18. Chaque mot travaille. "Aucune agence" remplace "aucune mise en vente prolongée" — plus percutant, aligne sur le différenciateur central de Versi. Le CTA "Demander une offre" dit exactement ce que fait le propriétaire — pas "nous parler", mais obtenir quelque chose de concret.

## 8. Cohérence de voix

### Analyse globale

La voix est **incohérente sur trois points structurels**.

**Incohérence 1 — "On" vs "Nous" vs "Versi"**
Le Hero et AvailableProperties utilisent "on" (registre oral, familier). Arguments et SellerBanner utilisent "Nous" ou "Versi" (registre institutionnel). Le brand voice est formel : "Nous ne déléguons pas" — pas "On ne délègue pas". Ce mélange casse l'unité de voix dès les deux premières sections.

**Incohérence 2 — Niveau de densité factuelle**
Stats = dense et précis (niveau versi.fr). TeamTeaser intro = vague et narratif (niveau brochure). Arguments = intermédiaire. Le lecteur passe d'un registre à un autre sans raison. Il faut aligner vers le haut — pas vers le bas.

**Incohérence 3 — CTA sans cohérence**
"Voir les appartements disponibles" (Hero) / "Tous nos biens" (AvailableProperties) / "Découvrir notre approche complète" (TeamTeaser) / "Nous parler de votre bien" (SellerBanner). Quatre CTA, quatre registres, aucune cohérence. Les CTA de versi.fr ont tous le même ADN : verbe d'action + complément court. Ici, c'est un patchwork.

Le "on" est une faute de brand voice répétée deux fois above the fold — c'est la première chose que lit un visiteur. Le Hero, qui est la section la plus lue de toute la homepage, est à 5/10. ## 10. Les 3 rewrites les plus urgents

**Priorité 1 — Hero (H1 + sous-titre)**
C'est le premier texte lu. Le "On" viole le brand voice. L'image "chaque mur" est trop lyrique. La redondance H1/sous-titre affaiblit les deux. Ce rewrite seul ferait passer la homepage de 6 à 7,5.

Rewrite :
```
H1 : Vingt et un appartements transformés.
     Vendus en direct. Sans agence.
Sous-titre : Vous traitez avec le propriétaire — celui qui a pris chaque décision.
```

**Priorité 2 — TeamTeaser (H2 + intro)**
L'intro est la phrase la plus faible de toute la homepage. "De A à Z", "elles-mêmes", la cascade de "qui... qui... qui..." — c'est du registre brochure immobilière standard. Et le H2 rate l'opportunité d'utiliser la formulation versi.fr.

Rewrite :
```
H2 : Trois fondateurs. Quarante-deux ans de terrain.
Intro : Thomas, Maxime et Carl portent chaque opération de l'acquisition à la vente.
        Ils visitent avec vous. Ils signent avec vous.
```

**Priorité 3 — Argument 1 (titre + description)**
La redondance avec le Hero dilue les deux sections. L'argument doit aller plus loin que "vous parlez au propriétaire" — déjà dit dans le Hero. Il doit nommer le cycle Versi avec précision.

Rewrite :
```
Titre : Acquis, transformé, vendu par nous.
Description : Chaque bien sur ce site, nous l'avons acheté.
              Nous avons piloté les travaux. Nous vous le vendons.
              Vous ne parlez à aucun intermédiaire à aucune étape.
```
